---
description: 在当前会话停用 advisor 审查副模型
---

帮助用户在当前会话停用 zcode-advisor：

1. 在当前上下文中查找以 `[advisor]` 开头的注册行（含"脚本"与"状态文件"两个绝对路径）。若找不到，回复："advisor 未在本会话挂载，无需停用。" 不要猜测路径。
2. 从注册行取出两个路径，运行（Bash）：

   ```
   node "<脚本绝对路径>" ctl off --state "<状态文件绝对路径>"
   ```

3. 报告输出，并说明：该开关只作用于注册行对应的那一个会话；重新启用用 /advisor-on。
